# Coach Fitness Website

![Screenshot](screenshot.png)

## Description

Ce projet est un **site web complet pour un coach fitness**, construit sur WordPress avec un thème personnalisé basé sur `ASTRA`.  
L'objectif était de créer un **site moderne, responsive et professionnel**, prêt à être utilisé comme portfolio ou vitrine pour un entraîneur personnel.

Le site a été initialement généré avec **ZipWP**, puis **adapté et personnalisé** pour enlever toute trace de thèmes prédéfinis comme Astra et créer un design **100% unique**.

---

## Fonctionnalités principales

- Page d’accueil moderne avec **hero section** et CTA.
- Pages internes :
  - About / À propos du coach
  - Services
  - Tarifs
  - Témoignages
  - Blog
  - Contact avec formulaire simple
- Responsive design pour **mobile, tablette et desktop**
- Navigation fluide entre toutes les pages
- Contenu entièrement personnalisé pour refléter un style professionnel
- Optimisé pour le portfolio : code propre, CSS/JS organisé
- Images et textes modifiables pour adaptation facile

---

## Technologies utilisées

- **WordPress** (CMS)
- **PHP, HTML5, CSS3, JavaScript**
- **Thème personnalisé** basé sur `_underscores`
- **Plugins utilisés** : aucun plugin propriétaire inclus (site statique exporté possible via Simply Static)
- Export possible en **site statique HTML/CSS/JS** pour hébergement gratuit (GitHub Pages, Netlify)

---

## Objectif du projet

- Démontrer mes compétences en **développement WordPress et personnalisation de thème**
- Créer un **portfolio pratique et concret**
- Appliquer les bonnes pratiques de design web, responsive et structuration de code
- Créer un site entièrement unique à partir d’un projet généré par IA (ZipWP) en **supprimant toutes traces de thème préexistant**

---

## Instructions pour visualiser le projet

1. **Site statique** : télécharger le projet et ouvrir `index.html` dans un navigateur.
2. **WordPress complet** :
   - Installer WordPress en local
   - Copier le thème `_underscores` depuis ce dépôt dans `wp-content/themes/`
   - Activer le thème et importer les contenus si besoin
