# Fitness-Coach-Website

Dieses Projekt ist eine **vollständige Website für einen Fitnesstrainer**, die auf WordPress mit einem benutzerdefinierten Theme basierend auf `ASTRA` erstellt wurde.  
Ziel war es, eine **moderne, responsive und professionelle Website** zu erstellen, die als Portfolio oder Schaufenster für einen Personal Trainer genutzt werden kann.

Die Website wurde ursprünglich mit **ZipWP** erstellt und anschließend **angepasst und individualisiert**, um alle Spuren vordefinierter Themes wie Astra zu entfernen und ein **100% einzigartiges** Design zu schaffen.

---

## Features
- Moderne Homepage mit **Hero-Bereich** und CTA.
- Interne Seiten :
  - Über den Coach
  - Leistungen
  - Blog
  - Kontakt per Formular
- Responsives Design für **Mobilgeräte, Tablets und Desktop-Computer**
- Nahtlose Navigation auf allen Seiten
- Vollständig individualisierbare Inhalte für einen professionellen Auftritt
- Portfolio-optimiert: sauberer Code, übersichtliches CSS/JS
- Bilder und Texte bearbeitbar für einfache Anpassung

---

## Tech Stack
- **WordPress** (CMS)
- **PHP, HTML5, CSS3, JavaScript**
- **Verwendete Plugins**: Keine proprietären Plugins enthalten (Export der statischen Website über Simply Static möglich)

---

## Objectif du projet

- Démontrer mes compétences en **développement WordPress et personnalisation de thème**
- Créer un **portfolio pratique et concret**
- Appliquer les bonnes pratiques de design web, responsive et structuration de code
